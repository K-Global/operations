## 2. Terminals & concourses

- **Terminal layout:** Historically a single main international/domestic terminal (five storeys, ~33,000 m², rated ~3M pax/yr capacity), plus an East/West terminal expansion project (contracted ~2007, never completed) and a separately-reopened VIP terminal (2017, less damaged). 🟧
- **Our operation uses:** Not applicable — no planned use of this field.
- **International arrivals / CBP hall:** Not applicable.
- **Notes:** Reported ~90% of airport facilities and ~20 aircraft destroyed in the 2014 Battle of Tripoli Airport; the main passenger terminal is described in public sources as effectively demolished, with jet bridges visible in satellite imagery still standing at former gate positions. A 2025 press report describes a first asphalt layer being laid on the runway under a resumed reconstruction effort — current facility status beyond that is unconfirmed. 🟥
