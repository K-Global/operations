## 9. Performance watch-items for our types

- **Field-length / weight:** Non-limiting — runways are built long for the altitude (Briefing §7).
- **Density altitude / temperature:** **Dominant driver.** Density altitude routinely exceeds 10,000 ft at ≈7,656 ft field elevation with typical 20–25 °C temperatures — verify take-off performance and SID climb-gradient compliance on every departure, especially warm/heavy.
- **Contamination / wet-runway:** Kiremt-season (Jun–mid-Sep) convective rain — braking-action consideration in the wet season.
- **Link to OM B:** See [`OM B — Fleet Capability Matrix`](../../../../../fleet/capability-matrix.md) for type-by-type hot-and-high performance reference.

## 10. Gotchas

- All runway ends have **displaced thresholds** — verify TORA/ASDA per direction before the performance calculation.
- SIDs/STARs are **actively changing by NOTAM** — never fly a name from memory; pull the current AIRAC cycle.
- High terrain close-in on multiple bearings — brief the engine-out/missed-approach climb gradient on every departure, not only when performance-limited.
