> **Read-me:** Tactical departure aid for the sim, not a chart. Companion to the [GVNP Briefing](index.md), [Dispatch](dispatch.md) and [Arrival](arrival.md) pages. GVNP's single 03/21 runway sits on **Santiago Island**, which — unlike flat Sal at [GVAC](../gvac/index.md) — has real inland terrain; treat any departure routing toward the interior with more care than the GVAC picture would suggest. SIDs/procedures are listed **by name only or flagged not-published** — fly the charted current-AIRAC version. Static data only; live wx/NOTAM/CTOT are pulled at planning. ## 10. Gotchas

- **No confirmed SID inventory, take-off minima, or EOSID** — pull the current-AIRAC procedures before flying this departure; this page cannot substitute for that.
- **Santiago Island has real inland terrain** — do not import GVAC's flat, benign departure picture; verify climb-gradient and terrain clearance on the current chart.
- **RWY 03's displaced threshold** does not affect TORA in the same way it reduces LDA — confirm the correct declared distance for the departure runway before performance planning (Briefing §7).
- **Single shared APP/TWR frequency** — expect a lower-density, possibly non-radar handoff structure; brief accordingly.
- **Airport concession changed hands in 2023 (Vinci Airports)** — infrastructure/procedure changes since then may not be reflected in older tier-4 sources; treat all data here as provisional pending AIP confirmation.
