## 5. Approach hazards (terrain / CFIT / specific threats)

- **CFIT / terrain:** 🟧 The field itself is coastal/flat (Bay of Gando, 78 ft) — non-threatening for a direct coastal approach. Gran Canaria's interior massif (~1,949 m, ~20 NM inland) is a real consideration for any procedure or diversion routing that isn't a direct coastal transition — cross-ref [Briefing §3.1](index.md).
- **Specific threats:** 🟧 Closely-spaced parallel runways (03L/21R, 03R/21L); persistent NE trade-wind gust/crosswind component; periodic Saharan-dust (calima) visibility reduction.
- **Airspace / traffic:** 🟧 Moderate density — **Canarias FIR/UIR (GCCC)**, a distinct oceanic-adjacent FIR with no dedicated OM C brief; see [Europe (Continental) Airspace Briefing](../../../../airspace/europe.md) for the nearest general reference (flagged gap, Briefing §18). Mixed international-jet and inter-island-turboprop traffic (Binter Canarias, Canaryfly).

## 10. Gotchas

- **Persistent NE trade-wind gust/crosswind on final** — brief for a stabilised-approach discipline given the routine gust component.
- **Closely-spaced parallel runways** — confirm correct runway assignment ("left/right") before briefing; don't assume independent simultaneous operations without checking the current AIRAC.
- **Interior massif ~20 NM inland (~1,949 m)** — respect MSA on any segment that isn't a direct coastal transition.
- **Seasonal Saharan dust (calima)** — monitor METAR/TAF trend; can reduce visibility sharply and quickly.
- **CAT III equipment-status check** before planning a low-vis approach, given the sub-category/runway designator is unconfirmed from a primary source.
- **Canary Islands run one hour behind mainland Spain (UTC+0/+1)** — a scheduling trap worth double-checking against any mainland-referenced planning time.
