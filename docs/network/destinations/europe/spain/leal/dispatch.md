## 2. Terminals & concourses

- **Terminal layout:** Single unified terminal building serving all traffic; a Schengen/non-Schengen airside segregation exists but the exact pier/gate split was not located in reachable sources. 🟧
- **Our operation uses:** Standard passenger terminal gate assignment per Aena/handling on the day.
- **International arrivals / CBP hall:** International arrivals clear passport control within the single terminal; no separate satellite hall identified.
- **Notes:** Alicante is a very high-volume seasonal leisure gateway (~19.95 M passengers in 2025) — expect peak-season terminal/stand congestion in summer months. 🟧

---

## 3. Stands / gates (by code letter & our fleet)

- **Widebody (Code E/F) stands:** Code E routine at **PRKG 200, 2, 4C**; Code F (up to A380/An-124) at **PRKG 2** and (lighter Code F, up to B744/A342/A124) at **PRKG 4C** — both require prior airport coordination, not ad-hoc. 🟧
- **Stands NOT usable by our types:** Narrowbody-oriented stands are not sized for Code E/F — confirm specific stand assignment with handling.
- **Remote / hardstand positions:** Not itemised in reachable sources beyond the Code E/F PRKG list above. 🟧
- **Contact vs remote for our arrivals:** Not confirmed; expect a mix given high seasonal traffic volume. 🟧
- **Ground-movement stand caveats:** **A346, A35K and B77W are restricted to TWY C8 only** — confirm current taxiway routing for any of these types. See [Briefing §13](index.md).

## 4. Slots, curfew & CTOT regime

- **Slot coordination level:** Not confirmed in reachable sources — no explicit IATA Level 2/3 designation found for LEAL; treat as unconfirmed pending VAMSYS/Aena confirmation. 🟧

Aena ran **temporary nightly runway closures (00:00–05:00 LT)** for maintenance/expansion in past seasons (e.g. 2–29 Mar 2026) — a scheduled one-off, check current NOTAMs for any recurrence. 🟧
- **CTOT / flow control:** Not independently confirmed; treat standard EUROCONTROL ATFM practice as a baseline assumption for a busy leisure gateway during peak banks. 🟧
- **Commercial impact:** High seasonal (summer) demand peak is the dominant scheduling consideration here rather than a curfew/slot constraint.
