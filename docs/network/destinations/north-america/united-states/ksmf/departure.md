## 2. Stand → runway taxi routing & hot spots

- **Typical routings by runway:** Not detailed in reachable sources; **VAMSYS taxi-out time is 10 min** (Dispatch §1). Push-back is **mandatory tail-to-north** from Terminal gates A1, A3, A5; West Ramp spots 63W/65W/66/F1 are tow-in/tow-out only via TWY B2, and ADG V aircraft on Spot 66 push onto TWY A only after ATC approval.
- **Hot spots / tight taxiways:** 🟥 **TWY Y4 and TWY B1 are restricted to aircraft with wingspan <118 ft (Group III)** — any widebody must avoid these and use the main parallel taxiways. A portion of **TWY W (500–2,100 ft east of TWY A) is not visible from the tower** — expect closer ATC coordination there.
- **Runway crossings / read-back-required points:** Not detailed in reachable sources — the two-parallel-runway layout is described as straightforward; confirm with Ground/current diagram. 🟧
- **Low-vis taxi caveats:** Not published — no SMGCS/follow-me detail confirmed for KSMF; Tule fog is the relevant seasonal trigger. 🟧

## 3. Runway / SID selection logic

- **By wind / config:** No formal preferential-runway program published. **17R/35L carries the CAT II/III ILS (ALSF2)** and is the natural low-vis preference; otherwise wind-driven, noting the Central Valley's afternoon "Delta breeze" shifts wind NW/W later in the day.
- **By departure direction:** Not detailed by direction in reachable sources — assigned per ATC/SID.
- **Noise / preferential-runway program:** Noise-sensitive area west of the field along the Sacramento River — avoid local turns for jet aircraft; VFR patterns planned to the east; minimum power settings requested.
- **Interaction with arrivals:** Radar Class C (NORCAL Approach/Departure), straightforward two-parallel-runway environment — no adjacent-FIR handoff complexity.

## 9. Performance watch-items for our types

- **Field-length / weight:** 🟩 Non-limiting — 8,598–8,605 ft parallel runways, no displaced thresholds, ample for widebody long-haul departure weight.
- **Density altitude / temperature:** 🟩 Non-issue — sea-level-equivalent field (27 ft), no hot-and-high penalty. Contrast with KRNO, where density altitude is the dominant performance driver.
- **Contamination / wet-runway:** Winter rain is the main contamination consideration; grooved concrete surfaces mitigate. Tule fog affects visibility, not runway contamination directly.
- **Link to OM B:** Field itself is non-limiting for the A330-900-class widebody; the material OM B cross-check is **ARFF Index C adequacy** for the type (Briefing §16), not takeoff performance.

## 10. Gotchas

- **TWY Y4/B1 wingspan restriction (<118 ft)** — any widebody must route via the main parallel taxiways, not these.
- **A stretch of TWY W is not visible from the tower** — expect closer ATC coordination taxiing through that segment.
- **Push-back is tail-to-north mandatory from certain Terminal A gates** — confirm the specific gate's push direction before requesting pushback.
- **Special (non-standard) take-off minimums exist but figures aren't public** — pull the actual RVR values from the current chart, don't assume standard minimums.
- **Noise-sensitive area west along the Sacramento River** — avoid local jet turns; plan VFR patterns east.
- **This is NOT a hot-and-high or terrain-constrained field** — unlike KRNO, standard sea-level departure planning applies; don't over-apply high-elevation caution here.
