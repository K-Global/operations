## 2. Terminals & concourses

- **Terminal layout:** The airport operates a single main passenger terminal building organised into concourses: **Concourse A** (10 gates), **Concourse B**, and **Concourse C** (24 contact gates + 44 remote positions, including gates built for the largest widebody types, opened 27 May 2014). Concourses **D and E** were folded into Concourse C's operation in 2021 ahead of their own expansion, which was completed under a **Phase B project in March 2025**.
- **Our operation uses:** Not confirmed — expect a Code E/F assignment in Concourse C consistent with its widebody-oriented layout, but this has not been independently verified for our operation. 🟧
- **International arrivals / CBP-equivalent hall:** International arrivals process through the main terminal per gate assignment.
- **Notes:** 🟧 Confirm current gate/concourse assignment with handling before finalising a stand plan — the concourse layout changed materially as recently as March 2025.
