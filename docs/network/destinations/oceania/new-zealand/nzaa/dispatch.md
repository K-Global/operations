## 2. Terminals & concourses

- **Terminal layout:** Auckland operates from a single integrated international terminal complex handling both international and domestic connections; specific concourse/pier lettering not confirmed in reachable public sources. 🟧
- **Our operation uses:** International arrivals/departures — confirm gate assignment with handling.
- **International arrivals / CBP-equivalent hall:** Customs/Immigration operates H24 `[AIP NZ AD 2 NZAA 2.3]`.
- **Notes:** No terminal-transition programme identified in reachable sources this pass.

---

## 3. Stands / gates (by code letter & our fleet)

- **Widebody (Code E/F) stands:** 🟧 **Code F (A380/B747-8) contact stands are 10, 15, 16, 17, 18**; **remote Code F stands are 19, 74, 75, 78, 79**. Standard Code E widebody stands not individually enumerated in reachable sources.
- **Stands NOT usable by our types:** Rapid-exit taxiways A4–A7 are not approved for Code F use; TWY B between B2–B6 is not available to Code F aircraft — factor into stand/routing planning for any A380/B747-8 rotation.
- **Remote / hardstand positions:** Remote Code F stands 19, 74, 75, 78, 79 as above; general remote-parking capacity not otherwise confirmed. 🟧
- **Contact vs remote for our arrivals:** Expect a contact gate for standard Code E widebody service; Code F may draw a remote position depending on schedule.
- **Ground-movement stand caveats:** A Code F aircraft cannot taxi behind a Code D/E/F aircraft holding TWY A1A–A10 inclusive — see [Briefing §13](index.md) and Departure/Arrival taxi sections.

---

## 4. Slots, curfew & CTOT regime

- **Slot coordination level:** None identified in reachable sources — Auckland manages its single-runway capacity through ATC sequencing rather than a published IATA slot level. 🟧
- **Curfew / night restriction:** **No general night curfew.** A **hard recurring runway closure Monday 0130–0430 local time** applies for maintenance — do not plan scheduled movements in this window. 🟥
- **CTOT / flow control:** Not confirmed in reachable sources; single-runway ATC sequencing is the operative constraint rather than a formal ATFM/CTOT programme. 🟧
- **Commercial impact:** The Monday maintenance closure is the one hard, recurring schedule constraint; otherwise, single-runway capacity means weather/incident-driven ground delay has an outsized effect on schedule integrity relative to a multi-runway hub.

## 5. Handling agents & turnaround

- **Handling agent(s):** **Air Center One**, **Skycare International**, **Air New Zealand**, **Menzies Aviation**, **Aerocare Flight Support**, **Eagleflight Aviation** (helicopter) are all named on-field agents `[AIP NZ AD 2 NZAA 2.4]`; the specific agent contracted for our operation is not confirmed. 🟧
- **Typical turnaround time for our type:** Not independently confirmed; VAMSYS mirror gives **taxi-in 13 min / taxi-out 16 min** for planning purposes `[VAMSYS mirror 2026-07-26]`.
- **Services:** Standard international widebody service (push-back, GPU/PCA, water/lav, catering, cabin clean) expected at a Code E/F contact stand.
- **Turnaround risk items:** Single-runway ATC sequencing during peak banks, Code F taxiway/stand restrictions if operating an A380/B747-8, and the wading-bird ATIS advisory near high tide can each add unplanned turn or taxi time.

## 10. Typical delays / reliability

- **Signature delay driver:** **Single-runway capacity** — any weather, incident or WIP-rehabilitation event on 05R/23L constrains the entire field, as there is no parallel runway to absorb the disruption.
- **Ground-delay / flow-program exposure:** Not independently quantified in reachable sources; treat single-runway saturation during peak banks as the primary exposure. 🟧

## 11. Curfew & noise-charge commercial impact

- **Noise-charge regime:** Noise abatement is prescribed under CAR Part 93, Subpart B (see [Briefing §12](index.md)); specific per-movement noise charging not confirmed in reachable sources. 🟧
- **Curfew infringement consequence:** No general curfew; the Monday 0130–0430 runway closure is a hard maintenance window, not a noise-driven curfew.
- **Scheduling guardrails:** Build the Monday maintenance window into any schedule touching NZAA in the small hours; otherwise treat single-runway weather/incident exposure as the main guardrail driver.
