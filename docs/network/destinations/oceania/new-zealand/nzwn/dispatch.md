## 2. Terminals & concourses

- **Terminal layout:** Single integrated terminal building; the **eastern apron** carries the aerobridge/mainline stands, the **western apron** serves general aviation, helicopters and an Execujet hangar (suitable to B737/A320) plus Capital Jet Services line maintenance.
- **Our operation uses:** Eastern apron aerobridge stands for scheduled service; confirm gate assignment with handling given the field's limited large-widebody stand infrastructure (§3).
- **International arrivals / CBP-equivalent hall:** Customs/Immigration operates H24 `[AIP NZ AD 2 NZWN 2.3]`.
- **Notes:** 🟧 Wellington's stand infrastructure is oriented toward narrowbody/single-aisle-widebody service — confirm suitability for the specific K Global type before scheduling.

---

## 3. Stands / gates (by code letter & our fleet)

- **Widebody (Code E/F) stands:** 🟧 Aerobridge-stand datum references A320 aircraft, **except Stand 23, which is referenced for B777** — this is effectively the field's only stand explicitly sized for a large widebody. Confirm current gate capability before planning any K Global type larger than a single-aisle/A320-class aircraft.
- **Stands NOT usable by our types:** Non-aerobridge stands (3, 4, 5, 6, 7–12, 18B, 19–20, 75–79) are general/GA-oriented; western apron is for GA/helicopters and is not intended for scheduled widebody service.
- **Remote / hardstand positions:** Stand 23 is available on request to Airport Operations 24 hr prior to arrival; Stands 22 and 24 are closed whenever an aircraft is parked on Stand 23 (adjacent-stand neutralisation, similar in principle to the paired-stand system at NWWW).
- **Contact vs remote for our arrivals:** Expect Stand 23 (if suitable to type) or an eastern-apron aerobridge stand for a scheduled arrival — confirm with handling.
- **Ground-movement stand caveats:** Code D/E aircraft enter/exit the runway system via TWY A1, A2, A10 or A11 only, and taxi to Stand 23 via TWY A and B6 — see [Briefing §13](index.md).

## 10. Typical delays / reliability

- **Signature delay driver:** **Windshear/turbulence from Cook Strait wind-channelling** — publicly documented go-around events (including on final approach) make this the field's clear leading reliability risk, more significant than any capacity or slot factor.
- **Ground-delay / flow-program exposure:** Single-runway ATC sequencing; the **12 NM ILS/LOC interference separation** in marginal weather (ceiling ≤1,000 ft/visibility ≤5 km) can add spacing delay to a following approach. 🟧
- **On-time reliability picture:** 🟧 Treat wind reliability as the dominant schedule-risk driver at NZWN; build alternate-diversion planning (NZAA/NZCH) into any schedule touching this field, especially in exposed wind conditions/spring months.
