## 4. Notes
- **Model/variant matching 🟥:** the SSG 747-8 package ships **both** the Intercontinental (8i) and Freighter (8F) as distinct loadouts with their own paint kits (main-deck side + nose cargo door art on the 8F, passenger door/window line on the 8i) — a house scheme must be painted **separately per variant** and is not interchangeable between the two. Confirm the correct variant kit before approving any livery. 🟥
- **Night-lighting / PBR:** SSG (XP11) lighting/PBR is of the XP11 generation — verify house-livery appearance on the actually flown build before approval 🟧 `[VERIFY]`.
- **Pending approval:** entire house scheme (both variants) is 🟧 pending; approve only after the Sim-Model decision (SSG 747-8, correct 8i/8F variant per tail) is closed, so each paint targets the correct kit.
- **Code F ramp/paint visibility 🟩:** no special paint constraint from Code F status — noted here only as a cross-reference to the Intro §4 / Checklist ground-handling flag, since these are the fleet's largest-footprint tails.
