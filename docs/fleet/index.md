# Fleet

Per-type airframe packs for the K Global fleet — the working detail that
applies [General (OM A)](../general/index.md) policy and
[Operations (OM E)](../flight-ops/index.md) method to a specific aircraft.
Every type carries a **six-file pack**: Intro, Dispatch, Sim-Model, Checklist,
QRH and Livery, reached from that type's page.

!!! info "Capabilities live in one place"
    Per-type EDTO/RVSM, PBN &amp; RNP AR, LVO, steep-approach, RECAT/wake and RFF
    are held in the **[Fleet Capability Matrix](capability-matrix.md)**. Airframe
    packs reference the matrix rather than restating values.

Folders are organised by **ICAO aircraft type designator**. Where a single
designator covers more than one variant — `A21N` covers the A321neo, LR and
XLR; `B748` covers the 747-8i passenger and 747-8F freighter — the variants
share one type page and are distinguished inside it. Seats and max-cargo figures
are indicative pending confirmation against the live fleet register; entries
tagged `[VERIFY]` are not yet checked.

## How each type page is structured

Each type page opens its **airframe pack** — a curated set of six files that
capture K Global's decisions for that aircraft:

- **Intro** — the airframe at a glance: variants operated, engines, key weights.
- **Dispatch** — planning data: performance, limits, loading, MEL considerations.
- **Sim-Model** — the approved simulator model and known fidelity notes.
- **Checklist** — the normal checklist in K Global standard form.
- **QRH** — abnormal and emergency reference.
- **Livery** — registration scheme and the type's place in the brand system.

Source-layer FCOM/QRH material informs the packs but is re-expressed, never
reproduced; references list public sources only.
