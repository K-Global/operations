## 4. Notes

- **Model/variant matching:** with no confirmed sim-model candidate (Sim-Model §1), there is currently **nothing** to paint a house scheme for — this ranks below the sim-model decision in sequencing. 🟥
- **Sub-variant care:** if the freeware A220-100 project is ever adopted as a stand-in, note it represents the shorter **-100**, not the K Global **-300** — any house paint would need to be checked for correct fuselage-length proportions before use, and clearly caveated as a sub-variant substitute.
- **Small fleet (5 tails):** unlike the multi-hub widebody packs, the BCS3 is a small, opportunistically-scheduled fleet based at EDDF — a single house-livery paint run (once a model is confirmed) would cover the type.
- **Pending approval:** entire house scheme is 🟧 pending; approve only after the Sim-Model decision (which add-on, if any) is closed, so the paint targets the correct kit.
