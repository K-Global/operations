# CONC — Concorde · Pack Index

> **ICAO type designator:** CONC · **Type rating:** its own unique type (no shared rating) · **Engines:** four — Rolls-Royce / Snecma **Olympus 593 Mk 610** afterburning turbojets, **reheat** fitted · **Crew:** three (Captain + First Officer + **Flight Engineer**)
> **Status:** 🟧 Pack complete (Draft v0.1) — all six files built from public SKYbrary / Heritage Concorde / Wikipedia data + VAMSYS mirror. Concorde is **unlike every other fleet type**: supersonic (**~Mach 2.04 at FL500–600**), **slender ogival delta with no flaps/slats**, **droop nose**, **reheat takeoff/transonic acceleration**, and **transonic CG managed by fuel transfer** — the defining 🟥 handling item. Sim-model = **Colimata Concorde FXP**, but the current **v3 is X-Plane 12-only**, so the XP11 fleet standard uses an earlier XP11 build `[VERIFY]` (Sim-Model §1). ## Signature items (🟥)

- **Transonic CG by fuel transfer** — fuel pumped aft (accel) / forward (decel) across the transonic region to track the aerodynamic-centre shift; CG and Mach are coupled (QRH Ch 6).
- **Reheat (afterburner)** — lit for takeoff and for transonic acceleration (M0.95→~M1.7), cancelled for supersonic cruise; very high fuel burn.
- **Droop (variable-incidence) nose** — 5° down (taxi/takeoff) / up (supersonic) / 12.5° down (landing) for visibility at the high delta pitch attitudes.
- **Three-crew flight deck** — Captain + First Officer + **Flight Engineer** (dedicated systems/fuel panel); unusual vs the two-crew glass fleet.
- **Supersonic environment** — skin/Mach-temperature limit (~127 °C region), ozone converters, cosmic-radiation monitoring with a descent limit at FL500–600.
