**Turboprop + high-speed premise 🟥:** this is the only turboprop pack in this group built out so far. It is powered by two free-turbine PW150A engines, each driving a six-blade constant-speed, fully-feathering propeller — control is split across a power lever (FADEC power command / ground-range blade angle) and a condition lever (propeller RPM/rating/feather/fuel cutoff), an architecture with no equivalent on the CRJ7/CRJ9 jets elsewhere in this group. It is also publicly marketed as one of the **fastest turboprops in production** (cruise up to ~360 KTAS) — do not brief it with slow-turboprop assumptions. See Intro §1–§2 and §6 for the full corrected premise.
