## 4. Notes
- **Model/variant matching:** ToLiss A319 uses its own dedicated A319 paint kit; JARDesign JD320 uses a generic A320-family kit — a house scheme would need painting **separately per model** and would not be interchangeable 🟧.
- **Night-lighting / PBR:** ToLiss (XP11) lighting is less refined than the XP12 edition; JD320 PBR differs again — verify house-livery appearance on the actually flown build before approval 🟧 `[VERIFY]`.
- **Small fleet, high substitution risk:** with only 6 tails (Dispatch §7 watch-item), any house-livery rollout should prioritise coverage across the whole type before partial-fleet painting, to avoid an unpainted tail being the only one available on a given day 🟧.
- **Pending approval:** entire house scheme is 🟧 pending; approve only after the Sim-Model decision (which add-on) is closed, so the paint targets the correct kit.
