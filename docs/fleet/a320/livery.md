## 4. Notes
- **Model/variant matching:** ToLiss's A320 base package is neo-generation — a house scheme targeting K Global's ceo-generation A320-200 must be painted for the **base+CEO-addon** paint kit (correct engine nacelles/wingtip standard), not the neo kit alone. JARDesign's single package switches wingtip/engine visually, so one paint kit serves both variants there. See Sim-Model §2 for the fidelity note. 🟧
- **Night-lighting / PBR:** ToLiss (XP11) lighting is less refined than XP12; JARDesign's rendering differs again — verify house-livery appearance on the actually flown build before approval 🟧 `[VERIFY]`.
- **Pending approval:** entire house scheme is 🟧 pending; approve only after the Sim-Model decision (which add-on, and CEO-addon presence) is closed, so the paint targets the correct kit.
