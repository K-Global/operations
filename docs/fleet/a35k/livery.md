## 4. Notes
- **Model/variant matching:** the FlightFactor A350 uses its own A350 paint kit; a **-1000** kit differs from the **-900** kit (fuselage length, door/window layout) — a house scheme must be painted to whichever variant is actually flown and would not be interchangeable between them 🟧.
- **Night-lighting / PBR:** FlightFactor (XP11) lighting is less refined than newer sims — verify house-livery appearance on the actually flown build before approval 🟧 `[VERIFY]`.
- **Pending approval:** entire house scheme is 🟧 pending; approve only after the Sim-Model decision (which add-on / which variant) is closed, so the paint targets the correct kit.
