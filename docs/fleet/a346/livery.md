## 4. Notes
- **Model/variant matching:** ToLiss's A340-600 ships its own paint kit and separate XP11/XP12 aircraft files (Sim-Model §2) — a house scheme must be painted for this specific kit and, if the weight-variant configuration (regular vs higher-gross-weight) affects registration data plates, confirm which variant the house tails represent 🟧 `[VERIFY]`.
- **Long-fuselage paint considerations:** at 75.36 m the -600's fuselage is the longest in the fleet — livery artwork spanning doors/windows/tail markings should be checked against the model's own template dimensions before commissioning a house scheme 🟧.
- **Night-lighting / PBR:** the XP11-specific aircraft file may not carry the same lighting/PBR refinements as the XP12 file (Sim-Model §3) — verify house-livery appearance on the actually flown build before approval 🟧 `[VERIFY]`.
- **Pending approval:** entire house scheme is 🟧 pending; approve only after the Sim-Model decision (candidate test-and-approve) is closed, so the paint targets the correct kit.
