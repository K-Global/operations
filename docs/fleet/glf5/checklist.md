# GLF5 — Gulfstream G550 · Normal Checklist

**GLF5 / Gulfstream GV-SP family** · flown as AKD Studio GLF550 (lead) / X-Hangar model (fallback) 🟧 `[VERIFY — model]` · sim = X-Plane 11
**Version** v0.1 · **Updated** 2026-07-25 · **Status** Draft

> **Read-me:** K Global normal-ops flow for X-Plane 11, adapted for the **Executive-unit VIP charter** paradigm (crew of two, 0–2 cabin attendants, point-to-point mission). **The aircraft's own checklist/CAS system is authoritative** — where the sim model differs from the real jet, the 🟧 note says so. This is a cockpit quick-reference, re-expressed in K Global's own words — **no verbatim OEM text**. Flag legend 🟥 memory/critical · 🟧 model-dependent · 🟩 normal.

---

*Format: **CHALLENGE …… RESPONSE**. Generic Gulfstream large-cabin twin flow, Honeywell Primus Epic-class ("PlaneView") avionics with head-up guidance and enhanced-vision fitted as standard on the type. Unlike the GLF6, the GLF5 uses **conventional mechanical/hydraulic flight controls** (control column, not fly-by-wire/side-stick) — a handling difference worth briefing pilots moving between the two Executive-unit types. Model-dependent items flagged 🟧 (mainly where the fallback model uses X-Plane's default systems rather than the lead model's custom simulation). Verify each item against the flown model before line use `[VERIFY]`.*

## Preflight / Cockpit prep
- Documents / OFP / navlog / VIP mission brief …… ABOARD, CHECKED
- Circuit breakers / covers / gear pins …… STOWED / NORMAL 🟧 (depth varies by model)
- Batteries (L/R) …… ON, VOLTAGE CHECKED (minimum per limits)
- External power / APU …… AS REQUIRED, POWER AVAILABLE
- Display units (4) …… NORM, CROSS-CHECKED
- Cabin pressure control …… SET (landing/auto as applicable), outflow valve verified open
- CAS / MEL …… REVIEWED, NO BLOCKING FAULT
- Fuel quantity / distribution …… CHECKED vs OFP
- Flight controls (mechanical, full-and-free) …… CHECKED 🟧 (check depth model-dependent)
- FMS init (route, performance, ZFW/CG, fuel) …… SET & CROSS-CHECKED
- Takeoff data (V-speeds, thrust rating/FLEX, trim, flap setting) …… ENTERED, CROSS-CHECKED, BOXED
- Baro / altimeters …… SET
- Departure brief …… COMPLETE

## Before start
- Cockpit prep …… COMPLETE
- Cabin (VIP pax / attendant if carried) …… BRIEFED, SECURE
- ATC / mission clearance …… OBTAINED
- Doors …… CLOSED, CAS DOORS PAGE CLEAR
- Fuel pumps …… ON
- Beacon …… ON
- Power levers …… IDLE
- Parking / emergency brake …… SET, ACCUMULATOR PRESSURE CHECKED
- Pushback / ramp area …… CLEAR, CLEARANCE RECEIVED

## After start
- APU bleed (for start) …… AS REQUIRED
- Engine start sequence …… STARTED, PARAMETERS NORMAL
- Anti-ice …… AS REQUIRED
- CAS …… CHECKED, NO ABNORMAL
- Ground equipment / external power …… DISCONNECTED, CLEAR

## Before taxi
- Flight controls …… CHECKED FULL & FREE 🟧 (mechanical system; check depth model-dependent)
- Flaps …… SET FOR TAKEOFF per performance
- Pitch trim …… SET per takeoff data
- Autobrake / anti-skid …… AS REQUIRED, ON
- Weather radar / EGPWS / stall barrier …… ON / AUTO / ON 🟧 (WXR fidelity varies by model and XP11 vs XP12)
- Takeoff CAS memo …… REVIEWED, NO ABNORMAL INDICATION
- Ground spoilers armed / cabin secure …… CHECKED

## Before takeoff 🟥
- **Cabin …… SECURE**
- **Flaps …… CONFIRMED per takeoff data**
- **Trim …… CONFIRMED SET**
- **Flight controls …… FREE & CORRECT**
- **Takeoff configuration (CAS memo clear) …… CONFIRMED**
- **Transponder / TCAS …… TA/RA, ON**
- **Runway / heading …… CONFIRMED, BOTH PILOTS — LINED UP**
- **Exterior lights …… SET FOR TAKEOFF**
- **Thrust-rating mode (TO/FLEX) …… CONFIRMED**

## After takeoff / Climb
- Landing gear …… UP, DOORS CLOSED
- Flaps …… RETRACTED ON SCHEDULE
- Ground spoilers …… DISARMED
- Climb thrust / autopilot …… SET, ENGAGED
- Air conditioning / pressurisation …… CHECKED, CLIMBING NORMALLY
- Baro → STD (at transition) …… SET
- Exterior lights …… AS REQUIRED

## Cruise
- Altitude / Mach …… SET per OFP (long-range cruise M0.80, high-speed cruise M0.85; up to M0.885 max operating) 🟩
- Step climbs …… AS PLANNED, TOC-driven
- Fuel …… MONITORED vs OFP, CROSSFEED CHECKED
- Long-range/oceanic routing …… ROUTE-BY-ROUTE MISSION PLANNING CONFIRMED (not an ETOPS/EDTO rule time — see Dispatch §5) 🟧
- Cabin altitude / pressurisation …… NORMAL
- Systems / CAS …… NORMAL

## Descent / Approach
- Descent / approach brief …… COMPLETE
- Baro (at transition level) …… SET
- Landing performance / VREF / flap setting …… CHECKED, SET
- Fuel …… SUFFICIENT, RESERVES CONFIRMED
- Cabin …… SECURE FOR LANDING
- CAS / autopilot …… SET FOR APPROACH
- Minima …… SET
- Steep-approach configuration (if flown) …… **NOT TO BE FLOWN UNLESS OPERATOR-APPROVED** — see Dispatch §6 🟥

## Landing 🟥
- **Cabin …… SECURE**
- **Landing gear …… DOWN, 3 GREEN**
- **Flaps …… LANDING SETTING PER PERFORMANCE**
- **Ground spoilers …… ARMED**
- **Autobrake / anti-skid …… SET AS REQUIRED, ON**
- **Landing CAS memo …… CLEAR**
- **Go-around altitude / thrust …… SET**

## After landing
- Ground spoilers / reversers …… STOWED
- Flaps …… RETRACTED
- Autobrake …… DISARMED
- APU …… START AS REQUIRED
- Weather radar …… OFF
- Transponder …… AS REQUIRED (standby/ground)
- Exterior lights …… AS REQUIRED

## Shutdown / Secure
- Parking brake …… SET (or chocks in)
- Engines …… OFF (fuel control levers OFF)
- Cabin signage / VIP handling …… COMPLETE
- Beacon …… OFF
- Fuel pumps …… OFF (as required)
- External power / APU …… AS REQUIRED
- CAS / doors …… CHECKED
- Aircraft …… SECURED (per secure-cockpit flow if last leg of the mission)
